# Result files

- main_six_metrics_raw.csv: run-level six-metric results for the main comparison.
- main_six_metrics_summary.csv: mean and standard deviation summaries.
- label_ratio_summary.csv: supervision-budget summaries.
- runtime_raw.csv: validated single-thread runtime observations.
- runtime_summary.csv: paired median runtime summaries.
- label_noise_raw.csv: run-level label-noise results.
- label_noise_summary.csv: label-noise summaries.
- label_noise_paired_ScaleSem_vs_HLPNMF.csv: paired label-noise comparison with HLPNMF.
- radial_mechanism_per_run.csv: run-level radial-mechanism diagnostics.
- radial_mechanism_summary.csv: radial-mechanism summaries.
- semantic_matrix_statistics.csv: semantic-matrix and scale statistics.
- tsne_stability.csv: t-SNE stability statistics.
- coil20_basis_similarity.csv: COIL20 basis-similarity statistics.

Large per-run model-state MAT files are not included.
