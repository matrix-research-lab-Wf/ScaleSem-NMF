# Release checklist

- [x] Core MATLAB R2019a solver included.
- [x] Self-contained synthetic example included.
- [x] MATLAB R2019a self-test completed successfully.
- [x] Frozen paper parameters and seeds included.
- [x] Compact raw and summary result CSV files included.
- [x] Current manuscript source, PDF and final PNG figures included.
- [x] Exact benchmark MAT files included with SHA-256 checksums.
- [x] Third-party baseline code excluded.
- [x] Internal absolute paths and transient build files excluded from tracked files.
- [ ] Select and add an open-source license.
- [ ] Confirm that public redistribution of each bundled dataset is permitted by its original provider.
- [ ] Confirm author names, affiliations, funding and CRediT roles before public release.
- [ ] Review the final staged Git diff before commit and push.
